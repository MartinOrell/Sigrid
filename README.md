# Sigrid
A simple tool to edit chess diagrams.

Compile:
````
cmake -B build
````
````
cmake --build build --config Release
````

Execute:
````
build\bin\Release\sigrid.exe
````

Program is built with:
* [SFML 3.1](https://www.sfml-dev.org/)
* [Native File Dialog Extended 1.3](https://github.com/btzy/nativefiledialog-extended)
